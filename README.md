# LearningLeagues-Lib

AI-first component library for [LearningLeagues](https://github.com/louistinti/LearningLeagues):
built by AI sessions under human locks, consumed by AI sessions writing product
code. The system it implements is specified by the SYSTEM-BLUEPRINT
(dated copy in `process/archives/`).

- **Agents start here:** [`AGENTS.md`](AGENTS.md) — the operating contract and
  reading order.
- **Humans start here:** [`process/PROJECT-CONTEXT.md`](process/PROJECT-CONTEXT.md).

## Status

Milestone 5 shipped: the token pipeline runs Figma → generated stylesheet
(128 tokens — colours, spacing, layout, typography and the extracted `type/*`
text styles), the conformity CI job blocks on 8 executable gates, the first
component (Button) went through the RFC circuit, and the documentation site is
generated from the component contracts.

- **Documentation site:** <https://louistinti.github.io/LearningLeagues-Lib/>
  — component registry, per-component pages, and the design-tokens reference.
  Regenerated by `pnpm docs:build`; content lives in the contracts, never in
  the site.
- **Theming:** single dark palette; one element-scoped accent axis
  (`data-accent`: `ambre`, `bleu`, `rouge`, `violet`, `jade`).
