# ORCHESTRATION — obligations indexed by trigger event

Re-consult this file at each event, not once. A trigger not listed here is not
necessarily covered elsewhere: if you cannot find the answer to "what am I now
obliged to do", that is a doctrine gap to flag, not one to fill by improvising.

| Trigger event                                                   | Obligation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| You are starting a fresh session                                | Read the documentation map in `AGENTS.md`, in order.                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| You are about to write code for a new component                 | STOP unless its RFC status is `approved` and you claimed ownership in the state manifest first.                                                                                                                                                                                                                                                                                                                                                                                                  |
| You are about to commit                                         | Run `git branch --show-current`; confirm it matches intent. Regenerate any artefact whose source you touched, in the same commit.                                                                                                                                                                                                                                                                                                                                                                |
| You are about to open a PR                                      | Run `pnpm conformity` and quote the executed verdict — one line. Body in five sections: Summary / Changes / Verification (the executed verdict) / Flags for review / Session report (the three blocks).                                                                                                                                                                                                                                                                                          |
| You renamed / changed the value of a colour token               | Re-run `pnpm gate:contrast` before committing — even for a change that looks minor; contrast is a property of pairs you have never seen.                                                                                                                                                                                                                                                                                                                                                         |
| You are adding a generator or a gate script                     | Same commit: `GENERATORS` in `check-drift.ts` (generator) or `GATES` in `check-conformity.ts` (gate), the `PLAYBOOK.md` row, and the red/green proof in `PROOF-OF-BLOCKING.md`.                                                                                                                                                                                                                                                                                                                  |
| You touched a gate's detector or scan surface                   | Re-prove that gate red/green and update `process/PROOF-OF-BLOCKING.md` — a gate is tested like any other code.                                                                                                                                                                                                                                                                                                                                                                                   |
| You created an RFC-stage component folder                       | A folder holding the RFC and `contract.json` (draft, not exported, a11y `pending`) but no `*.meta.ts` is RFC stage (arbitrated 2026-09-11 at the second component): the docs and dist generators and the a11y engine leave it out VISIBLY (a `skipped` log line, a `SKIPPED (RFC stage)` row); the status gate still requires the draft contract, prettier-formatted. The moment a `*.meta.ts` exists the folder must be complete — the scaffold creates it after approval, never a hand before. |
| You added a new component scaffold                              | The scaffold is red on purpose — proof that gates aren't default. Never silence a violation (no allowlist, no bypass, no deleted check): fix them, in this order: token-lint → contrast → contract.json. The RFC is a precondition (approved before any code) that the scaffold never overwrites — not a violation to fix afterwards.                                                                                                                                                            |
| You are adding an allowlist entry                               | STOP: only a named human approves one. Shape (`scripts/lib/allowlist.ts`): a top-level `description` and `entries[]` of `{ scope, reason, approvedBy, added, expires }`, dates `YYYY-MM-DD`; the loader rejects blank approvers, thin reasons and missing expiry.                                                                                                                                                                                                                                |
| You are asked to review another session's work                  | Zero write on that branch unless the human authorises it; the deliverable is a report.                                                                                                                                                                                                                                                                                                                                                                                                           |
| Your CI went red                                                | Classify: needs-fixing-red (fix it) vs expected-red (token gate awaiting the human label — wait). Never work around; never report one as the other.                                                                                                                                                                                                                                                                                                                                              |
| You are about to add a dependency                               | Declare it in every manifest the consumer path reads (root proxy + package). Flag the bump policy question in the PR if ambiguous.                                                                                                                                                                                                                                                                                                                                                               |
| A required external input is unavailable                        | STOP and report. Never improvise the value it would have given.                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| You are about to push                                           | Read `git log origin/main..HEAD --format='%h %an %s'` and the trailers: every commit on the intended branch, no foreign trailer, nothing on local `main` (L13, L14).                                                                                                                                                                                                                                                                                                                             |
| A subagent committed on your branch                             | Before push, verify its commits' branch, author and trailer as your own; rewrite a foreign trailer before push, never after (L13).                                                                                                                                                                                                                                                                                                                                                               |
| Someone reports a push you cannot see                           | Run `git ls-remote <remote> <branch>` and quote the SHA. Without it the push did not happen: report, do not record (L15).                                                                                                                                                                                                                                                                                                                                                                        |
| A gate reds on a component by design, not by defect             | Report it as a suspected false positive — a closed question to the human. If confirmed, the rule change goes in its own commit with red/green proofs and under Flags for review. Never an allowlist (L17).                                                                                                                                                                                                                                                                                       |
| The design lead edited the Figma node after the RFC was drafted | Re-read the node and record a §7 row (his words verbatim, what changed); annotate every earlier row it reverses as superseded; re-check §3–§4 against the node.                                                                                                                                                                                                                                                                                                                                  |
| You are about to measure or edit a consuming repository         | `git fetch` and verify the tree sits on `origin/main` (L09). Pushing there is a human lock (`AGENTS.md`).                                                                                                                                                                                                                                                                                                                                                                                        |
| You are delegating components to parallel subagents             | One worktree per component (`git worktree add .claude/worktrees/<kebab> -b <type>/<kebab>`), its manifest claim as that branch's first pushed commit. The brief names the only paths the subagent may write; a needed shared-source change comes back to the orchestrator as a blocker. Subagents never ask the human: the orchestrator batches every component's closed questions into one arbitration round, and relays answers verbatim into each RFC §7.                                     |
| A sibling component PR merged while yours is open               | Sync the branch with `main`; on a manifest conflict keep both rows as each branch wrote them. Never hand-merge a generated file: take `main`'s side, then `pnpm docs:build` and `pnpm dist:build`, commit, and re-run `pnpm conformity` before asking for the next merge.                                                                                                                                                                                                                        |
| You finished a major session (pipeline, refactor)               | Propose a hygiene audit (inventory → plan → human approval → execute) — `process/HYGIENE-AUDIT.md`.                                                                                                                                                                                                                                                                                                                                                                                              |
| You learned something generalisable in review                   | Write it to `LEARNINGS.md` (Active section) before the review is done, with the gate that does not exist yet.                                                                                                                                                                                                                                                                                                                                                                                    |
| You are ending the session                                      | Report in three blocks: To understand / To decide / To paste, including Decisions made autonomously (each block defined in `AGENTS.md`, Agent behavior rules).                                                                                                                                                                                                                                                                                                                                   |
